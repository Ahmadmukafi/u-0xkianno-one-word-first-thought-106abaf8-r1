Entry for the make.fun bounty **One Word, First Thought** — send exactly one word, the first that comes to mind, and let a judge compare it two at a time on which is more interesting.

## The word

**serendipity** — a lucky accident worth keeping. One word, vivid and unexpected, the kind of word that stands out against safe filler.

## How it works

`main.ts` writes exactly `serendipity` (11 bytes, no trailing newline) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

```sh
node main.ts
```
